# Design

Production membership comes only from a fresh live production sitemap capture. Current local membership comes from a read-only agency query. Join exact slugs to local rows and createResolvedSlugOwnerLookup; join canonical Agency IDs to persisted source mappings through canonical IO. Never use the August backup to assert present production membership or invent source IDs. Preserve fetched XML, hashes, query results, and exact mapping evidence. Every production-only mismatch is accounted for as resolved or explicitly unresolved.

Preserve the old root envelope as evidence. Amend each applicable source namespace list through InitialAgencyRoots canonical IO after mapping is verified. Review namespace findings before changing the shared empty-agency-table gate; a list-only change must not be falsely reported as importing records that cannot be reached under that gate.

The user selected established source-backed survivors for duplicate production agency pages and expressly ordered the three duplicate Texas pages removed from local/future builds. Retire these three manual identities through the existing source-exclusion data mechanism. Verify the live local database, build projection tables and active source artifacts contain none of the rejected IDs/slugs, and verify manual transform exclusion using attempted restoration records. No runtime implementation, viewer changes, general delete behavior, or invented replacement IDs are required. Keep the retired legacy seed as historical evidence; current reset explicitly uses --no-seed and Supabase sql_paths is empty.

For the four confirmed overlapping federal offices, amend the durable federal source forward mappings and corresponding reverse mappings to the selected TCOLE Agency identities. Back up the replaced mapping files and preserve the established survivor slug caches. Retire stale reverse mappings from active state while retaining their bytes in audit evidence. This changes identity data only, not import selection or runtime behavior. Distinct offices and agencies remain separate.
