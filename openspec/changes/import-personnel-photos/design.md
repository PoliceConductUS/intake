Store one explicit personnel_photo row per personnel, with intake-ledger id, workspace-relative path, SHA-256, byte size, MIME type, original source filename and optional verified source URL. CLI validates an exact existing personnel id and uses the shared source-name ledger to establish its namespace reference. It appends a typed photo record to the existing manual source; ordinary transform/generate/up compares and applies it. Image bytes live under assets/PersonnelPhoto/<sha256>.<extension>. Website queries that association, validates bytes, and stages the image under public/img/personnel-photos. Missing associated bytes fail loudly; no association keeps the existing default portrait. No filename-to-person identity inference.
