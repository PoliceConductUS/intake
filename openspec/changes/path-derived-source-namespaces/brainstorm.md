## Outcome

A source has one name wherever it is selected, run, logged or referenced. Its directory provides the namespace. A developer can locate the implementation, retained inputs and command results using the same slash-delimited name.

## Naming decisions for review

Use the path below the configured sources directory. Use the publishing organization's domain in reverse order, followed by the source-specific path needed to distinguish its feeds. Distinguish publisher identity from the service that hosts or retrieves its content. Intake owns the landing page search workflow.
