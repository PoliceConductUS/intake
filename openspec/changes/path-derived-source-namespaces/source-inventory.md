# Source namespace inventory

Paths below are relative to `sources/`. Each destination directory contains `intake.source.ts`.

| Previous name                    | Source namespace                                       | Input or issuing organization                                                                                                                                                                  |
| -------------------------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `clearinghouse-api`              | `net/clearinghouse/api`                                | Clearinghouse case records come from clearinghouse.net/api/v2p1.                                                                                                                               |
| `courtlistener`                  | `com/courtlistener/www/api`                            | The CourtListener API supplies docket records from www.courtlistener.com. Complaint PDFs use storage.courtlistener.com.                                                                        |
| `gov.ar.clest`                   | `gov/arkansas/dps/clest`                               | Request-only. CLEST receives requests through dps.arkansas.gov.                                                                                                                                |
| `gov.azpost.roster`              | `gov/az/post/roster`                                   | Local roster workbook. Arizona POST identifies itself at post.az.gov. The transform is disabled.                                                                                               |
| `gov.de.post`                    | `gov/delaware/post`                                    | Request-only. The state POST commission receives requests through delaware.gov.                                                                                                                |
| `gov.fl.cjstc`                   | `us/fl/state/fdle/cjstc`                               | Request-only. The Criminal Justice Standards and Training Commission receives requests through fdle.state.fl.us.                                                                               |
| `gov.irvingtx.arrests`           | `gov/irvingtx/arrests`                                 | Local Irving Police Department workbook. The city uses irvingtx.gov. Separately acquired geographic evidence includes city map layers and Census data.                                         |
| `gov.ms.bleost`                  | `gov/ms/dps/bleost`                                    | Request-only. The board receives requests through dps.ms.gov. A NextRequest case tracks correspondence.                                                                                        |
| `gov.or.dpsst`                   | `net/bpl-orsnapshot/www/public-inquiry-cj`             | The Oregon CJ IRIS personnel search downloads data from www.bpl-orsnapshot.net/PublicInquiry_CJ/. The issuing agency is Oregon DPSST.                                                          |
| `gov.sc.letc`                    | `gov/sc/sccja`                                         | Request-only. South Carolina Criminal Justice Academy identifies itself at sccja.sc.gov. Its submission form is hosted by Cognito Forms.                                                       |
| `gov.tx.tcole`                   | `gov/texas/tcole`                                      | Local Texas Commission on Law Enforcement workbook. The commission uses tcole.texas.gov.                                                                                                       |
| `gov.us.federal-le`              | `org/wikipedia/en/us-federal-law-enforcement-agencies` | The list is retrieved from en.wikipedia.org. Intake reviews agency candidates from that page.                                                                                                  |
| `gov.wi.lesb`                    | `gov/wisdoj/lesb`                                      | Request-only. The Wisconsin Law Enforcement Standards Board receives requests through wisdoj.gov.                                                                                              |
| `gov.wv.leps`                    | `gov/wv/das/leps`                                      | Request-only. The West Virginia Law Enforcement Professional Standards Subcommittee is listed by das.wv.gov.                                                                                   |
| `landing-page-search`            | `com/serpapi/landing-page-search`                      | SerpApi supplies the Google search results. Search Console provides query and landing-page pairs. Article evidence comes from each publisher.                                                  |
| `mn-post`                        | `com/site/my/mnitservices/post-license-search`         | The POST license search reads the roster from mnitservices.my.site.com/POSTLicenseSearch/. Agency CSVs also come from mn.gov/post and disciplinary documents from the supporting file service. |
| `org.policeconduct.manual`       | `org/policeconduct/manual`                             | PoliceConduct staff create the manual records locally.                                                                                                                                         |
| `org.policeconduct.submissions`  | `org/policeconduct/submissions`                        | PoliceConduct submissions are stored in its configured private S3 bucket.                                                                                                                      |
| `us-census-gazetteer`            | `gov/census/www2/gazetteer`                            | Gazetteer and TIGER data files are downloaded from www2.census.gov. The catalog page is on www.census.gov.                                                                                     |
| `us-officer-sex-crime-reporting` | `org/psvproject/arrest-tracker`                        | The [Police Sexual Violence Project arrest tracker](https://www.psvproject.org/2026-arrest-tracker) publishes the separate 2025 and 2026 workbooks on Google Sheets.                           |
| `youtube.policeactivity`         | `com/youtube/policeactivity`                           | PoliceActivity publishes the channel on YouTube. The module reads the YouTube Data API and downloads available captions separately.                                                            |
