1. Specify the native record contract and source/producer ownership before implementation.
2. Write failing native facade and lifecycle tests.
3. Add the forward migration preserving historical array evidence; regenerate canonical IO with the existing introspector and generator against disposable PostgreSQL.
4. Register annotations through the ordinary descriptor, facade, source-name ledger, manual source, and Artifacts flow. Validate polymorphic subject references through shared reference resolution.
5. Produce corrections, validation findings, and exclusion findings during normal generation. Resolve obsolete intake-produced findings while preserving other producers. Inspect merged effective values for partial updates.
6. Remove annotation arrays, source-contribution apply hooks, post-apply scanning, and obsolete commands. Keep up/replay ordinary mutation application.
7. Export the updated downstream contract and validate native source/index consumption.
8. Run targeted lifecycle regressions, full tests, format, typecheck, build, OpenSpec, and SQL validation. Use only disposable databases for migration/reset evidence.
