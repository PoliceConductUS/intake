# com

## Overview

Groups the intake sources whose reversed-domain namespace starts with `com`. Each source folder exports a `source` from `intake.source.ts` with its phases.

## Subdirectories & Boundaries

- courtlistener: [./courtlistener/README.md](./courtlistener/README.md) - `com/courtlistener/www/api`: civil cases from CourtListener that name an officer of a known agency.
- serpapi: [./serpapi/README.md](./serpapi/README.md) - `com/serpapi/landing-page-search`: daily news search for profile pages, published to the selected website release.
- site: [./site/README.md](./site/README.md) - `com/site/my/mnitservices/post-license-search`: Minnesota POST agencies, officers, licenses and discipline.
- youtube: [./youtube/README.md](./youtube/README.md) - `com/youtube/policeactivity`: PoliceActivity channel videos linked to the officers they name.
