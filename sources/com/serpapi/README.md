# serpapi

## Overview

Groups the intake sources under the reversed domain `com/serpapi`. It holds one source, `com/serpapi/landing-page-search`.

## Subdirectories & Boundaries

- landing-page-search: [./landing-page-search/README.md](./landing-page-search/README.md) - The landing page search source. Its `daily` phase reads Search Console traffic for profile pages, searches Google through SerpApi for news stories, and publishes matched stories to pages of the selected website release.
