# mnitservices

## Overview

Groups the intake sources whose namespace starts with `com/site/my/mnitservices`. It holds one source, `com/site/my/mnitservices/post-license-search`.

## Subdirectories & Boundaries

- post-license-search: [./post-license-search/README.md](./post-license-search/README.md) - The Minnesota POST source. `acquire` saves agency rosters, officer details and disciplinary order documents from the MN POST license search; `transform` emits agency, personnel, license, education, discipline and coverage-link artifacts.
