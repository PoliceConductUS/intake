# gov/census

## Overview

Groups the intake sources for the US Census Bureau. It holds no code of its own.

## Subdirectories & Boundaries

- [www2](./www2/README.md) - Holds `gov/census/www2/gazetteer`: the US Census Gazetteer and TIGER source; acquires the newest shared Gazetteer and TIGER year and produces `LocationPaths`, `LocationPathAliases`, and `LocationPathGeometries`.
