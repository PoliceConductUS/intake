# gov/census/www2

## Overview

Groups the intake sources served from the Census host `www2.census.gov`. It holds no code of its own.

## Subdirectories & Boundaries

- [gazetteer](./gazetteer/README.md) - Source namespace `gov/census/www2/gazetteer`: the US Census Gazetteer and TIGER source; acquires the newest shared Gazetteer and TIGER year and produces `LocationPaths`, `LocationPathAliases`, and `LocationPathGeometries`.
