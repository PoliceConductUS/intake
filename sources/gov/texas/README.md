# gov/texas

## Overview

Groups the intake sources for Texas state government. It holds no code of its own.

## Subdirectories & Boundaries

- [tcole](./tcole/README.md) - Source namespace `gov/texas/tcole`: the Texas TCOLE source; transforms the TCOLE public-information workbook into `LicensingAuthorities`, `AuthorityLicenses`, `Agencies`, `Personnel`, `Licenses`, `LicenseActions`, `AgencyPersonnel`, and `AgencyPhoneNumbers`.
