# net

## Overview

Groups the intake sources whose reversed domain starts with `net` (the `.net`
top-level domain). It holds no code of its own.

## Subdirectories & Boundaries

- bpl-orsnapshot: [./bpl-orsnapshot/README.md](./bpl-orsnapshot/README.md) -
  holds `net/bpl-orsnapshot/www/public-inquiry-cj`, the Oregon DPSST public
  roster, employment history and certifications source (acquire and transform
  phases).
- clearinghouse: [./clearinghouse/README.md](./clearinghouse/README.md) -
  holds `net/clearinghouse/api`, the Civil Rights Litigation Clearinghouse
  source that produces `CivilCases`, `CivilCasePersonnel` and `CivilCaseLinks`
  artifacts (acquire and transform phases).
