# net/bpl-orsnapshot

## Overview

Groups the intake sources whose data comes from `bpl-orsnapshot.net`, the host
of the Oregon DPSST public inquiry site. It holds no code of its own.

## Subdirectories & Boundaries

- www: [./www/README.md](./www/README.md) - sources served from
  `www.bpl-orsnapshot.net`. Holds `net/bpl-orsnapshot/www/public-inquiry-cj`,
  the Oregon DPSST roster, employment history and certifications source.
