# org/wikipedia

## Overview

Intake sources whose data is acquired from Wikipedia, grouped by language
edition. There is no code directly in this folder.

## Subdirectories & Boundaries

- en: [README](./en/README.md) - sources acquired from English Wikipedia;
  currently the `org/wikipedia/en/us-federal-law-enforcement-agencies` source,
  which produces the `FederalAgencies` and `Agencies` artifacts.
