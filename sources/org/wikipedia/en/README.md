# org/wikipedia/en

## Overview

Intake sources whose data is acquired from English Wikipedia. There is one
source in this folder and no code directly in it.

## Subdirectories & Boundaries

- us-federal-law-enforcement-agencies:
  [README](./us-federal-law-enforcement-agencies/README.md) - source that saves
  the Wikipedia list of US federal law-enforcement agencies, writes a
  candidates list and a curated agency list to state, reads a curated
  `offices.yaml` from state (no code writes that file), and produces the
  `FederalAgencies` and `Agencies` artifacts.
