# us

## Overview

Groups the intake sources whose reversed domain starts with `us` (the `.us`
top-level domain). It holds no code of its own.

## Subdirectories & Boundaries

- fl: [./fl/README.md](./fl/README.md) - Florida sources. Holds
  `us/fl/state/fdle/cjstc`, the public-records `request` declaration for the
  Criminal Justice Standards & Training Commission; it has no acquire or
  transform phase.
