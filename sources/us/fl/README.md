# us/fl

## Overview

Groups the intake sources whose reversed domain starts with `us/fl` (Florida,
`*.fl.us`). It holds no code of its own.

## Subdirectories & Boundaries

- state: [./state/README.md](./state/README.md) - Florida state government
  sources. Holds `us/fl/state/fdle/cjstc`, the public-records `request`
  declaration for the Criminal Justice Standards & Training Commission.
