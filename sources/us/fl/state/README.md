# us/fl/state

## Overview

Groups the intake sources for Florida state government domains
(`*.state.fl.us`). It holds no code of its own.

## Subdirectories & Boundaries

- fdle: [./fdle/README.md](./fdle/README.md) - Florida Department of Law
  Enforcement sources. Holds `us/fl/state/fdle/cjstc`, the public-records
  `request` declaration for the Criminal Justice Standards & Training
  Commission.
