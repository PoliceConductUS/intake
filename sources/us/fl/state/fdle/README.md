# us/fl/state/fdle

## Overview

Groups the intake sources for the Florida Department of Law Enforcement
(`fdle.state.fl.us`). It holds no code of its own; the one source under it is
`us/fl/state/fdle/cjstc`.

## Subdirectories & Boundaries

- cjstc: [./cjstc/README.md](./cjstc/README.md) - source
  `us/fl/state/fdle/cjstc`. Declares the public-records `request` to Florida's
  Criminal Justice Standards & Training Commission; it has no acquire or
  transform phase.
